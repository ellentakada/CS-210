Summarize the project and what problem it was solving.
- The project prompts and displays time in 12 hours and 24 hours format. The menu has an option to add one hour, one minute, or one second to the initial input. This option can be repeated until a user selects "Exit Program".

What did you do particularly well?
- I did particularly well in displaying clock in correct format. For example, adding one hour to 23 p.m. would yield 0 a.m. in input, and sames goes for minutes and seconds.

Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?
- The program offers simple features of displaying and updating time. It would be nice to have advanced clock display such as converting to different timezone. 

Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?
- The most difficult part was fine tuning the "Add One Second". It took an effort to implement a condition to adjust hours and minutes when adding one second to 59 seconds. 

What skills from this project will be particularly transferable to other projects or course work?
- I was able to use techniques learned from previous lessons, such as using setw() to control displayed characters in a feasible way. This is a practical way than typing many characters manually.

How did you make this program maintainable, readable, and adaptable?
- By following the principal to break down each functionality to each method, it is much more readable and understandable than writing everything in main. When troubleshooting, calling certain functions can isolate which function is causing an error.
